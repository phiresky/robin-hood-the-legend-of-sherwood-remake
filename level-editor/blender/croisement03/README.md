# Croisement03 refinement

Private work and frozen source evidence live in
`level-editor/work/croisement03-refinement/`. These recipes do not modify the
published editor library. Crossings03 is the English task name for Croisement03.

`setup_scene.py` imports the archived volume scene, freezes source artwork and
masks, and records a 107-mesh inventory. `source_evidence.py`, `survey.py`,
`mask_survey.py` and `source_inventory.py` retain animation frames and complete
native source scope. `catalog.py` accounts for all 106 native obstacle parts in
42 logical groups; obstacle coverage does not include all painted assets.
The timber bridge, undergrowth, moving water, supplemental stems and mission
objects still need independent owners and modeled appearances.

The source survey covers both occlusion layers, all four obstacle sheets and all
nine mask sheets. Mask candidates are not blanket material ownership. Keep
foreground foliage off wood and stone, and retain initial/applied state identity.
Layer1 duplicate masks do not imply duplicate physical assets.

Use only the Leicester southeast cottage tree and Leicester moat bank tree as
supplementary tree construction references, together with this map's native
artwork. Complete off-map geometry, use crown depth at least its width unless
source evidence supports another proportion, and inspect actual saved materials
from all eight views. Gray source-only faces are unknown surface evidence.

All Blender work acquires the shared four-slot render pool. Workspaces freeze
comparison cameras and exact source hashes. Run `group_scene.py` once after the
source grouping survey; `refine_firewood.py` creates the first private candidate.
Its source-fit, actual-material and neighbor checks must pass before readiness.
No geometry approval, texture approval or publication is implied by a recipe
completing. Follow the shared refinement procedure for those gates.
